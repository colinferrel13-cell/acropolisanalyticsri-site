For authors & educators

Add a QR code to a document

Choose a single image above, or download all topic and collection codes together.

Download all QR codes (ZIP)
  1. Choose the destination. A topic code opens its library page, not an individual PDF. Future releases use the same address.
  2. Insert the image. Use SVG for scalable print artwork or PNG for an image-based layout. Keep it square, with its original white margin.
  3. Test the finished page. Print the destination URL beside the code. Scan a proof at its final size and confirm it opens the intended topic.
