    Publish through GitHub

    1. Sign in to the website repository and create a new review branch from the latest main. Confirm that its current library/catalog.json matches the one you started with. When in doubt, select that branch's catalog above and prepare again.
    2. Enter that branch's name below and open its upload page. Upload the entire package into library/ together. Only the existing catalog.json should be replaced; PDF filenames must be new.
    3. Open a pull request to main. Check that no existing titles are removed. The only change to a prior entry should be a homepage spotlight you intentionally reassigned. Review the PDF editions and any publisher link, then merge after checks pass.
    4. After GitHub Pages publishes the change, open the listing and test its view and download links.

    Use a new branch with letters, numbers and hyphens. This link cannot create a branch or log you in.
